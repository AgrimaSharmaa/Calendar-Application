# Calendar Application (Java)

A dynamic and optimized console-based Calendar application written in Java to compute and display formatted monthly calendars.

## Features
- **Dynamic Grid Rendering:** Computes exact weekday starting positions for any given year and month.
- **Leap Year Logic:** Built-in validation algorithm to handle February date constraints accurately.
- **Clean Console Output:** Formatted grid alignment using standard Java printing utilities.

## Tech Stack
- **Language:** Java (JDK 8 or above)
- **Concepts Used:** Object-Oriented Logic, Control Flow, Console I/O, Scanner Class
